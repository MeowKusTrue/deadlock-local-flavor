# Local Flavor 1.1.0

Выбирайте каждую часть коллекции отдельно: 20 установочных ZIP, включая 12 автомобильных вариантов.

- ATM 1.1: светлый экран без белых полос, исправленный низ и скруглённые боковины.
- Аудио 1.3: покупка и повышение способности чуть громче; короткий джингл без ускорения.
- Белый/жёлтый Haval, ДПС с синими номерами, гладкие грузовики Яшкино и все сочетания. Один автомобильный ZIP одновременно.
- Обновлённый DMM Import с названиями и обложками. Обычные ZIP содержат только VPK.

Для новых звуков используйте лавку Original Sounds. Старые сборки остаются в релизе 1.0.0. Выбор и превью — в README.

Проверены ZIP/VPK, контрольные суммы и пересечения ресурсов. Новые сборки проверены офлайн; игровой тест каждой новой сборки ещё не выполнен. Дополнительное нижнее меню подвала пока не входит в релиз.
