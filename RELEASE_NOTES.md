# Deadlock Local Flavor 1.2.0

Лавка «Вкусно — и точка», HUD-меню, указатели у подземных лавок, банкомат ЗБЕР, звуки, Haval-такси, ДПС и Яшкино.

Выберите один полный набор **White/Yellow** или нужные модули по отдельности. Для автомобилей есть одиночные и готовые комбинированные варианты.

Закройте игру, отключите старые версии и импортируйте выбранные ZIP через **Add Local Mod**. Полный набор не смешивайте с отдельными модулями; автомобильный архив — один за раз.

Для названий и обложек распакуйте **DMM Import** и откройте `mod-interchange.json` через импорт библиотеки. Это набор карточек для выбора, а не единый устанавливаемый мод.

[Что выбрать, превью и установка](https://github.com/MeowKusTrue/deadlock-local-flavor#readme)
