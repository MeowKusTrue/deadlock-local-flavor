# Яндекс Go — классическое такси / Classic taxi

Версия / Version: **1.0**

![Preview](../../assets/taxi.png)

Рендер Blender без генерации изображения ИИ. / Ordinary Blender render, no AI image generation.

Это окраска исходной машины Deadlock, не Haval и не Hyundai. Пять оболочек размещены через отдельную модель грузовика; исходная игровая коллизия сохранена. Работа подтверждена автором в игре. Отключите другие версии такси и моды того же грузовика.

A livery for the original Deadlock car, not a Haval or Hyundai. Five shells use a separate truck model as their carrier; original taxi collision remains. Confirmed in-game by the author. Disable other taxi variants and replacements of that truck.
