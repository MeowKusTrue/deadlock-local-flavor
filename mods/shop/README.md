# Вкусно — и точка / Original sounds

Версия / Version: **1.2**

![Preview](../../assets/shop.jpg)

Обложка сделана с помощью ИИ и не является игровым скриншотом. / AI-assisted promotional cover, not a game screenshot.

Выберите один основной вариант. Для своего сочетания звуков используйте Original Sounds и нужные Extra-файлы. Мелодия лавки — обработанная петля длительностью 9 секунд. Звук повышения способности относится к этому моду, а не к HUD-меню.

Choose one main variant, or Original Sounds plus individual Extras. Ambience loops for nine seconds. The ability upgrade sound belongs to the shop audio options, not the HUD menu.
