# Полная коллекция1.2.0

White и Yellow отличаются цветом Haval-такси. Каждый архив содержит всю коллекцию: лавку, HUD, 16 табличек, ATM, все звуки, ДПС и Яшкино.

Выберите только один полный ZIP и выключите все отдельные модули коллекции. Для самостоятельного набора используйте раздельные архивы вместо полного.
