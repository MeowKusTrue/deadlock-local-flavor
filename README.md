# Deadlock Local Flavor

Лавка «Вкусно — и точка», меню предметов, банкомат ЗБЕР, указатели, такси Яндекс Go, ДПС и грузовики Яшкино для Deadlock.

[Скачать](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/latest) · [Установка](docs/INSTALL_RU.md) · [Совместимость](docs/COMPATIBILITY.md) · [English](README.en.md)

## Всё одним архивом

Выберите **White** с белыми Haval или **Yellow** с жёлтыми. В каждом уже есть вся коллекция: лавка, HUD, таблички, банкомат, все звуки, такси, ДПС и Яшкино. Включайте один полный набор, отключив отдельные модули коллекции.

## Собрать свой набор

Вместо полного набора можно выбрать моды по отдельности. Лавка, HUD, таблички и банкомат работают независимо. Автомобильный архив выбирается один; звуки — по составу без дублирования.

## Установка

1. Закройте Deadlock и скачайте выбранные ZIP из раздела **Assets** релиза.
2. Отключите прежние версии и лишние варианты.
3. В мод-менеджере выберите **Add Local Mod**, импортируйте нужные ZIP и включите их.

Полный набор и отдельные модули не смешивайте. В каждом установочном ZIP один VPK в корне.

Для готовых названий и обложек скачайте [DMM Import 1.2.0](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/download/v1.2.0/Deadlock_Local_Flavor_DMM_Import_v1.2.0.zip), распакуйте его и откройте `mod-interchange.json` через **Add mods → Open export file…**. Карточки добавляются выключенными — включите выбранный совместимый набор. [Подробнее](docs/MOD_MANAGER.md).
