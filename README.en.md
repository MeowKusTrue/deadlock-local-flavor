# Deadlock Local Flavor

Cosmetic Deadlock mods by MeowKusTrue: a fast-food shop, matching item menu, entrance signs, Zber ATM, optional audio, Yandex Go taxis, Haval traffic police and Yashkino trucks.

[Downloads](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/latest) · [Full catalog and previews](README.md) · [Compatibility](docs/COMPATIBILITY.md)

Choose independent visual and audio modules. Enable only one vehicle ZIP: prebuilt combinations cover all choices of white/yellow Haval, police and trucks. Purchase and ability audio are separate or combined. Use the Original Sounds shop with new audio; disable old audio variants.

Each installation ZIP contains one VPK at its root. The separate DMM Import library bundle provides names and cover URLs; extract it and import mod-interchange.json. All cards start disabled.

Updated binaries were checked offline, including ZIP layout, hashes and resource intersections. Every exact new build has not yet been tested in-game. No full-map or collision replacement is included. [Credits](docs/CREDITS.md).
