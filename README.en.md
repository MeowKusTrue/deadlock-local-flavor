# Deadlock Local Flavor

Cosmetic Deadlock mods by MeowKusTrue: a fast-food shop, item-shop UI, entrance signs, Zber ATM, optional sounds, Yandex Go taxis, Haval police and Yashkino trucks.

[Download](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/latest) · [Installation](docs/INSTALL_EN.md) · [Русский](README.md)

## What to choose

1. If you want vehicles, choose **one** vehicle ZIP below. Otherwise skip vehicles entirely.
2. Add any independent visual modules: shop model, item-shop UI, entrance signs and ATM. UI and physical menu boards are separate mods.
3. Add purchase, ability and/or music audio. Use either Purchase_Ability or the two separate Purchase and Ability files. Never enable all three. Audio works without the custom shop model.

### Disable before updating

- ATM 1.0 or another ATM replacement when enabling ATM 1.1.
- Old Extra_Purchase_Only, Extra_Ability_Only and shop variants 02_Shop_Sounds / 03_Ability_Sound / 04_All_Sounds when enabling audio 1.3. Switch the visual shop to Original Sounds. Add Music separately if wanted.
- Every other vehicle ZIP, previous Haval/Yashkino/police tests, Hyundai and taxi-hiding diagnostics when enabling a vehicle variant.
- Old versions within each group. Independent visual groups can remain enabled together.

## Install

Close Deadlock, download the chosen ZIPs and import each through Add Local Mod. Enable only the selected compatible files. Each normal ZIP contains one root-level VPK.

For ready-made names and covers, extract [DMM Import 1.1.0](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/download/v1.1.0/Deadlock_Local_Flavor_DMM_Import_v1.1.0.zip) and open mod-interchange.json through Add mods → Open export file…. Cards start disabled. Do not import that whole library ZIP as one mod.

## Validation and credits

ZIP layout, hashes, model dependencies and resource intersections were checked offline. Every exact new build has not yet been tested in-game. No full-map or collision replacement is included. The original geometry remains beneath vehicle overlays. Ability overrides soundevents/ui.vsndevts_c and conflicts with other replacements of that file. ATM has no 115-FZ destroyed-screen variant yet.
