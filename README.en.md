# Deadlock Local Flavor

Cosmetic Deadlock mods by MeowKusTrue: a fast-food shop, item-shop UI, entrance signs, Zber ATM, optional sounds, Yandex Go taxis, Haval police and Yashkino trucks.

[Download](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/latest) · [Installation](docs/INSTALL_EN.md) · [Русский](README.md)

## Full collection or individual mods

Choose [Complete White](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/download/v1.2.0/Deadlock_Local_Flavor_Complete_White_v1.2.0.zip) or [Complete Yellow](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/download/v1.2.0/Deadlock_Local_Flavor_Complete_Yellow_v1.2.0.zip) to install everything in one VPK. Use one complete archive **instead of** every individual module.

For a custom selection, use the tables below. [All Sounds](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/download/v1.2.0/Local_Flavor_Audio_v1.4_All_Sounds.zip) bundles ambience, purchase and upgrade; do not enable it with the individual audio variants.

## What to choose

1. If you want vehicles, choose **one** vehicle ZIP below. Otherwise skip vehicles entirely.
2. Add any independent visual modules: shop model, item-shop UI, entrance signs and ATM. UI and physical menu boards are separate mods.
3. Choose All_Sounds; or Music + Purchase_Ability; or your selected individual Music/Purchase/Ability files. Do not duplicate bundle contents. Audio works without the custom shop model.

### Disable before updating

- Older ATM versions or another ATM replacement when enabling ATM 1.3.
- Old Extra_Purchase_Only, Extra_Ability_Only and shop variants 02_Shop_Sounds / 03_Ability_Sound / 04_All_Sounds when enabling audio 1.4. Switch the visual shop to Original Sounds. Add Music separately if wanted.
- Every other vehicle ZIP, previous Haval/Yashkino/police tests, Hyundai and taxi-hiding diagnostics when enabling a vehicle variant.
- Old versions within each group. Independent visual groups can remain enabled together.

## Install

Close Deadlock, download the chosen ZIPs and import each through Add Local Mod. Enable only the selected compatible files. Each normal ZIP contains one root-level VPK.

For ready-made names and covers, extract [DMM Import 1.2.0](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/download/v1.2.0/Deadlock_Local_Flavor_DMM_Import_v1.2.0.zip) and open mod-interchange.json through Add mods → Open export file…. Cards start disabled. Do not import that whole library ZIP as one mod.

## Validation and credits

ZIP layout, hashes, model dependencies and resource intersections were checked offline. The user confirmed the previous vehicle, audio and signs corrections in-game. ATM 1.3 repairs the 1.2 frame regression and was verified offline; this exact new frame is not yet game-confirmed. The last opposite entrance sign was added using the real geometry without another test release. No full-map or collision replacement is included. The original geometry remains beneath vehicle overlays. Ability overrides soundevents/ui.vsndevts_c and conflicts with other replacements of that file. ATM has no 115-FZ destroyed-screen variant yet.
