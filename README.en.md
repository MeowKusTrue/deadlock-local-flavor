# Deadlock Local Flavor

A fast-food shop, item-shop UI, Zber ATM, entrance menus, Yandex Go taxis, police Haval and Yashkino trucks for Deadlock.

[Download](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/latest) · [Русский](README.md) · [Installation](docs/INSTALL_EN.md)

## Installation

Close Deadlock. Disable older versions, import the chosen ZIPs through **Add Local Mod**, then enable them. Use a complete set OR separate modules, never both. Each installation ZIP contains one VPK at its root.

For names and cover cards, extract [DMM Import 1.2.0](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/download/v1.2.0/Deadlock_Local_Flavor_DMM_Import_v1.2.0.zip) and open `mod-interchange.json` through **Add mods → Open export file…**. Entries start disabled; enable your compatible selection. [Details](docs/MOD_MANAGER.md).
