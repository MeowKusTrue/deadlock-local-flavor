# Установка

1. Закройте Deadlock.
2. Скачайте один полный набор White/Yellow или отдельные модули из [каталога](../README.md).
3. Отключите прежние версии и пересекающиеся варианты.
4. Импортируйте установочные ZIP через Add Local Mod и включите выбранное.

Полный набор уже содержит всю коллекцию. При выборе отдельных модулей автомобильный архив только один, звуки — без дублирования.

Для готовых названий и обложек есть [DMM Import](MOD_MANAGER.md). Для удаления выключите соответствующий мод в менеджере.
