# Установка

1. Закройте Deadlock.
2. Скачайте нужные ZIP из [Releases](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/latest).
3. Импортируйте каждый ZIP через Add Local Mod в мод-менеджере. Внутри один VPK в корне.
4. Отключите старые версии. Включите один полный набор White/Yellow ИЛИ нужные независимые модули с одним автомобильным вариантом. Полный набор уже содержит все модули коллекции.

Для новых звуков используйте лавку Original Sounds. Аудио выбирайте по одной схеме: All_Sounds; либо Music + Purchase_Ability; либо нужные одиночные Music/Purchase/Ability. Не дублируйте содержимое.

Для карточек с обложками используйте [пакет DMM Import](MOD_MANAGER.md). Его нужно распаковать и открыть JSON как экспорт библиотеки, а не добавлять целиком как локальный мод.

[Выбор модов](../README.md) · [Совместимость](COMPATIBILITY.md)

Для удаления выключите соответствующий мод в менеджере. Локальные GitHub-моды не обновляются через каталог GameBanana: следующую версию скачайте из Releases.
