# Установка

## Через Deadlock Mod Manager

1. Закройте Deadlock.
2. Скачайте нужный ZIP из Assets в [Releases](https://github.com/MeowKusTrue/deadlock-local-flavor/releases/latest).
3. В **Mods Library → Add Local Mod** выберите ZIP. Распаковывать обычный установочный архив не нужно.
4. Добавьте мод, выберите его VPK и включите. Для лавки включите только один основной вариант.
5. Убедитесь, что старая версия и другая замена того же объекта выключены. Запускайте игру.

Чтобы получить готовые названия и обложки, используйте [пакет импорта карточек](MOD_MANAGER.md).

## Вручную

Обычный ZIP содержит один VPK. Найдите папку Deadlock через Steam → Свойства → Установленные файлы → Обзор и откройте `game/citadel/addons`. Извлеките VPK туда под свободным именем `pakNN_dir.vpk`, например `pak80_dir.vpk`. Не заменяйте чужой файл с тем же именем. Для каждого VPK нужно своё свободное число.

Настройку загрузки addons удобнее доверить менеджеру. Если игра не подхватывает моды, проверьте её по [официальной инструкции DMM](https://docs.deadlockmods.app/using-mod-manager/getting-started); не копируйте целиком `gameinfo.gi` из другой версии игры.

## Обновить или удалить

Выключите старую версию и импортируйте новую. При ручной установке запомните, какое имя дали своему VPK, и заменяйте или удаляйте только его. После изменений перезапускайте игру. Для локальных модов обновления из GitHub нужно скачивать самостоятельно.

## Что делать при проблеме

Оставьте включённым только проблемный мод и повторите проверку. Если он работает отдельно, проверьте [пересечения](COMPATIBILITY.md). Если нет — [создайте issue](https://github.com/MeowKusTrue/deadlock-local-flavor/issues/new?template=bug_report.yml), укажите архив, дату обновления игры и приложите скриншот.
