# Карточки модов в Deadlock Mod Manager

1. Скачайте DMM Import нужной версии из Releases и распакуйте архив целиком.
2. Откройте `mod-interchange.json` через **Add mods → Open export file…**. Оставьте папки `files` и `assets` рядом с JSON.
3. Импортируйте нужные карточки и включите совместимый набор. Карточки изначально выключены. Для обложек нужен интернет.

Не добавляйте DMM Import как единый мод через Add Local Mod. Для этого пункта предназначены отдельные установочные ZIP.

## English

Download and fully extract the DMM Import archive. Open `mod-interchange.json` through **Add mods → Open export file…**, keeping `files` and `assets` next to it. Import the entries you want and enable a compatible set. Entries start disabled; cover images require internet. Do not import the library ZIP as a single local mod.
