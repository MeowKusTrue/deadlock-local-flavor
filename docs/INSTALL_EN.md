# Installation

1. Close Deadlock.
2. Download one complete White/Yellow set OR your chosen individual modules from the [catalogue](../README.en.md).
3. Disable previous versions and overlapping variants.
4. Import the installation ZIPs through Add Local Mod and enable your selection.

A complete set already includes everything. With individual modules, choose one vehicle archive and avoid duplicate audio contents.

For names and covers use [DMM Import](MOD_MANAGER.md). To remove a mod, disable it in the manager.
